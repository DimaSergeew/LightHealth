# Media checklist

The current listing uses `gallery.png`. For the next listing refresh, record one
short 16:9 clip at 1080p and export a lightweight WebP or GIF showing:

1. Aim at a healthy mob and pause long enough to show look-at inspect.
2. Hit the mob once to show the hologram, action bar, and floating damage number.
3. Land a critical hit to show the distinct crit number.
4. Run `/lh toggle`, then aim again to demonstrate that feedback is private and optional.

Keep chat, debug overlays, unrelated scoreboards, and server branding out of frame.
The first two scenes should fit within the first five seconds because listing
previews often autoplay without sound.
