# SpigotMC resource text (copy-paste)

The plugin is listed on SpigotMC for discovery, but it is a **Paper** plugin.

## Short tagline

```text
Modern mob HP feedback for Paper, Purpur & Folia — hologram, damage numbers, actionbar, bossbar, look-at.
```
